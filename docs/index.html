Stefan's Kodi Repository

A growing collection of Kodi add-ons.

Download the repository ZIP:

repository.stefan-commits-1.0.0.zip

In Kodi, enable Unknown sources under Settings → System → Add-ons. Choose Add-ons → Install from zip file and select the downloaded repository ZIP. Then choose Install from repository → Stefan's Kodi Repository.

Available add-ons

  • Stefan's Kodi Repository 1.0.0 · Source
  • NordVPN CLI 6.0.4 · Source

NordVPN CLI requires Kodi 19 or newer on Linux and the installed NordVPN Linux app. It is an unofficial community add-on.

Enable automatic add-on updates in Kodi to receive future published versions.
